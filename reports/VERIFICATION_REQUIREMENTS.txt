COMMON EVIDENCE PACK FOR EACH GUIDE
1. Disposable Windows 11 fixture: edition, release/build, architecture, local or
   remote host, shell edition/version, relevant tool versions and install method.
   Include a versioned fixture/config and lockfile if packages are involved.
2. Original failure: complete message, exact command/click path, starting settings
   and command resolution. Redact secrets and personal paths. Screenshots are
   optional and must be captured from the actual test if used.
3. Cause isolation: change one variable, preserve initial settings, record why
   another plausible cause does not explain this fixture.
4. Fix: exact diff/settings change, commands, actual output and exit codes.
   Avoid logging unrelated environment variables or production credentials.
5. Repeat on a clean fixture; record supported alternatives and failure boundaries.
   No benchmark/experience claim without underlying records and author confirmation.
6. Named technical review and author review; source references checked for pinned
   versions. Owner approval is separately REQUIRED before CMS insertion/publication.
